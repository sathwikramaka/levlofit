## Chapter overview
HYROX is a race with a fixed format: 1 km of running followed by one functional workout station, repeated eight times. {hyrox} Because the format is fixed, you can train for exactly what race day will ask.
> warn: Check the current rules
> Weights, distances and format details are set by HYROX and can change. Check the current official rules before a race. {hyrox}

## The eight stations, in race order
| Order | Station |
| 1 | SkiErg |
| 2 | Sled push |
| 3 | Sled pull |
| 4 | Burpee broad jumps |
| 5 | Rowing |
| 6 | Farmers carry |
| 7 | Sandbag lunges |
| 8 | Wall balls |
A 1 km run comes before every station. {hyrox}

## Training the stations
This is practical guidance. Practise the same eight movements in the same order, in circuits you can scale. Start with fewer rounds and add more as you improve.
If you lack equipment, use the closest substitute and be clear with yourself that it is not the real station. A bike or rower can stand in for a SkiErg, and a bodyweight walking lunge can stand in for sandbag lunges.

## Race strategy
This is practical advice too.
- **Pace your runs as well as your stations.** A common mistake is treating the runs as recovery. Both cost you time on the clock.
- **Choose a pace you can hold for all eight runs,** not just the first three.
- **Build up in stages.** Start with one station and its run, then half the format, then all eight, moving on when the shorter version feels comfortable.
Combined training generally does not hurt strength or muscle gains. {schumann2022} See [[combining-training|Combining different kinds of training]].

## Key takeaways
- The format is fixed: 1 km of running and one station, eight times.
- Check the current rules before racing.
- Practise the real order, and use honest substitutes.
- Pace for all eight runs.
- Build up in stages.
