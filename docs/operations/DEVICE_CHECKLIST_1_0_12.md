# Device checklist: Levlofit 1.0.12 on a real Android phone

About 20 minutes. Covers what 1.0.11 and 1.0.12 added that a browser cannot show. Use your own account; everything you
log is yours and can be deleted. Write Pass / Fail and a note (what you saw) in the last column. Screenshots of failures help.

| # | Do | Expect | Result |
|---|---|---|---|
| P1 | Open the installed older version | "Update ready" card that cannot be dismissed; Update installs 1.0.12 over it, data kept | |
| P2 | Within about a day of the next release, with the app closed | One notification "Levlofit 1.x is ready"; tapping it opens the app (Android may delay it; battery saver can hold it) | |
| P3 | More | Settings is its own row under Account; Profile has no Settings row | |
| P4 | Home screen: long-press, Widgets, "Levlofit today", place it | Two rows tall; shows today's session (or Rest day) and sessions this week; tap opens the app | |
| P5 | Log today's session, go back to the home screen | Widget says "<session>, done" within a minute | |
| P6 | Next morning, before opening the app | Widget says "Open Levlofit to see today", not yesterday's "done" | |
| P7 | Sign out | Widget empties to "Open Levlofit to see today" | |
| P8 | Start a workout, log a set, leave to Today, wait 5 minutes, reopen and finish | Calendar shows the session minutes counted from the first opening, not from the reopen | |
| P9 | Log a set heavier than any before on that move | Strong vibration, "New best on ..." note, the card marked "New best" | |
| P10 | Progress: Share on the weekly report (a week with training) | Android share sheet with a square dark picture: wordmark readable, sessions, streak; no food or weight | |
| P11 | Reminders: turn on Morning check-in and Meal nudges; next day tap each notification | Check-in opens Levlofit AI; a meal one opens Diet; Sunday 7 pm recap opens Progress | |
| P12 | Tap the same kind of reminder twice on different days without closing the app | Opens its screen both times | |
| P13 | Handbook | 69 chapters in six volumes; lists, tables and notes show (not blank) | |
| P14 | Levlofit AI: "How much protein do I need?" | Answer cites a Handbook book chapter; no error | |
| P15 | Today's read card | Opens a Handbook chapter | |
