## Chapter overview
Good technique means repeating the same movement, under control, through a range you own. Learn each lift light, and add weight only when every rep looks and feels the same.

## The six movement patterns
| Pattern | Example | Main muscles |
| Squat | Goblet squat | Thighs and hips |
| Hinge | Romanian deadlift | Hamstrings, hips and back |
| Push | Push-up, bench press | Chest, shoulders and triceps |
| Pull | Row, pull-up | Back and biceps |
| Single leg | Split squat, step-up | Legs and balance |
| Carry | Farmers carry | Grip and trunk |

## Learning a new lift
> tip: Levlofit rules
> These are Levlofit coaching rules, not research findings; technique coaching is hard to test in trials. A qualified coach can check your form in person.
- **Start light.** Bodyweight, a light dumbbell or an empty bar.
- **Same setup.** Place your feet, hands and grip the same way on every rep.
- **Control the way down.** Lower the weight under control instead of dropping into the bottom.
- **Use the range you own.** Go as deep as you can while keeping your position, without pain.
- **Check it.** Film one set from the side and compare it with the exercise demo.
- **Then add weight.** Only when every rep looks the same, keeping 2 to 3 reps in reserve while you learn.

## When to add weight
| Ready for more weight | Fix before adding weight |
| Every rep has the same speed and shape | Reps change shape or speed as the set goes on |
| You finish the set with reps in reserve | You reach failure earlier than planned |
| No pain in any joint, during or the next day | Joint pain during or after the lift; see [[injury-prevention|Injury prevention]] |
The practice loop is simple: learn it light, repeat it often, film and check, then add a little.

## Key takeaways
- Six patterns cover most training: squat, hinge, push, pull, single leg and carry.
- Learn each lift light with the same setup and a controlled way down.
- Add weight only when every rep looks the same and nothing hurts.
