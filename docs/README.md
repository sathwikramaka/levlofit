# Levlofit documents

| Folder | What is in it |
|---|---|
| `product/` | **The six living documents**, kept current with every change: `PRD`, `TRD`, `APP_FLOW`, `UI_UX_DESIGN_BRIEF`, `BACKEND_SCHEMA`, `IMPLEMENTATION_PLAN`. Also `OWNER_DECISIONS` |
| `release/` | `RELEASE_RECORD` (what shipped), `RELEASE_CHECKLIST`, `MIGRATION_RECONCILIATION`, setup, Play and iOS notes |
| `operations/` | Backup and recovery, device checklists, test plans, AI provider notes |
| `legal/` | Licences and sources, privacy self-review, outstanding reviews |
| `content/` | Handbook plans and reviews, exercise animations |
| `archive/` | Finished plans and audits, kept as history. Not current; do not act on them |
| `PROGRESS.md` | Running log of the work |

Start with `product/IMPLEMENTATION_PLAN.md` for what is done and what is next.
